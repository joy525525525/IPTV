## ✨ 特性

- 🇨🇳 **国内可用** — 已移除所有海外 IP 源，保留国内运营商、CDN 及国内 IP 源
- ⚡ **测速精选** — 每个频道经并发测速（延迟 + 下载速度），仅保留最优 2-3 个
- 📡 **多源备用** — 每个频道保留多个源，自动切换不卡顿
- 🗑️ **精简卫视** — 卫视频道仅保留 31 个省级卫视，移除地方小台
- 🖼️ **自带台标** — 包含频道 logo 和 EPG 电子节目单
- 📦 **体积极小** — 仅 70KB，加载速度快

## 🔧 处理流程

### 1. 国内可用筛选

- ✅ 保留：中国移动 IPTV 源（`chinamobile.com`）、国内官方 CDN（咪咕、央视频、央视、阿里云、百度、快手等）、国内 IP 段源、`.cn` 域名源
- ❌ 移除：414 个海外 IP 源（美国/欧洲 IP 段，国内直连不可用）
- ⚠️ 代理 API 源作为备用保留

### 2. 速度与稳定性测试

- 25 并发测试，超时 8 秒
- 测量指标：DNS 解析、TCP 连接、首字节时间（TTFB）、32KB 下载速度
- 综合评分 = 可用性(50) + 速度(30) + 延迟(20)
- 测试结果：1170 个源中 869 个可用（74%）

### 3. 精选保留

- 每个频道按评分排序，保留最优 2-3 个可用源
- 无可用源的频道直接移除（共移除 75 个，主要为 NewTV 轮播、部分台湾频道、电视剧轮播）
